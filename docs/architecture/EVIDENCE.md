# Evidence

## Definition

Evidence is information that confirms or disproves a Project State, Decision or Change.

Evidence represents the basis on which a project fact can be considered verified.

## Purpose

The purpose of Evidence is to connect project knowledge with observable and verifiable information.

## Properties

Evidence:

- has an identifiable source;
- may have a timestamp;
- may have an author or origin;
- can support or contradict a Project State;
- can support or contradict a Decision;
- may confirm that a Change was completed;
- must be traceable to the object it validates.

## Examples

Evidence may include:

- test results;
- measurements;
- documents;
- source code commits;
- screenshots;
- logs;
- inspection records;
- approvals.

## Relationships

Evidence may:

- validate or invalidate Project State;
- support or challenge Decisions;
- confirm completed Changes;
- be referenced by Work Items.

## Rule

A statement is not considered a verified Project State fact merely because it was discussed or recorded.

It must be supported by Evidence or explicitly marked as unverified.
