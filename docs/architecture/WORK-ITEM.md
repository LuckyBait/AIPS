# Work Item

## Definition

A Work Item is a unit of work created to implement one or more Decisions.

## Purpose

A Work Item represents planned or ongoing work that moves the project toward its target state.

## Properties

A Work Item:

- has an objective;
- may have an owner;
- may have a priority;
- has a lifecycle;
- may implement one or more Decisions.

## Relationships

A Work Item may:

- implement Decisions;
- produce Changes;
- reference Evidence;
- affect Project State indirectly through Changes.

## Rule

A Work Item itself does not modify the Project State.

Only completed Changes modify the Project State.
