# Project State

## Definition

Project State is the collection of verified facts that describe the current state of a project.

It does not describe intentions, ideas or plans.

## Purpose

Project State provides a single, consistent view of the project at any point in time.

## Properties

A Project State item:

- represents a fact;
- can be verified;
- may change over time;
- has evidence or can reference evidence;
- may be affected by one or more decisions.

## Does NOT contain

Project State does not contain:

- ideas;
- proposals;
- planned work;
- assumptions.

Those belong to other concepts.

## Relationships

Project State is connected to:

- Decision
- Work Item
- Change
- Evidence

## Rule

If something has not happened yet, it is not part of the Project State.
