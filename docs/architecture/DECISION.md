# Decision

## Definition

A Decision is a recorded choice that changes or constrains the future development of a project.

A Decision is not:

- a task;
- an idea;
- a project state;
- an implementation.

## Purpose

The purpose of a Decision is to make important choices explicit and traceable.

## Lifecycle

A Decision may have one of the following states:

- Proposed
- Accepted
- Rejected
- Superseded

## Relationships

A Decision may:

- create Work Items;
- affect Project State;
- be supported by Evidence;
- result in one or more Changes.

## Rule

A Decision does not change the Project State by itself.

Only completed Changes may modify the Project State.
