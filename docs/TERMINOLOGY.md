# AIPS Terminology

## Project

A container that defines the scope, participants and lifecycle of work.

## Decision

A recorded choice that changes or constrains the future development of the project.

## Project State

A collection of verified facts describing the current state of the project.

## Work Item

A unit of work created to implement one or more decisions.

## Change

A recorded modification that transforms one project state into another.

## Evidence

Information that confirms or disproves a project state or a decision.

## Knowledge

Structured information consisting of entities, relationships, decisions, states and evidence.
