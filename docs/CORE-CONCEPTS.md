# AIPS Core Concepts

The AIPS domain model is based on a small set of core concepts.

## Project

Defines the scope of work.

## Decision

Represents a recorded choice that influences the future of the project.

## Project State

Represents the verified current state of the project.

## Work Item

Represents work required to implement one or more decisions.

## Change

Represents a recorded modification of the project state.

## Evidence

Represents information that confirms or disproves a project state or decision.

## Relationship

Core concepts are connected through explicit relationships, allowing complete traceability across the project.
