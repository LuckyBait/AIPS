# AIPS Vision

## Purpose

AIPS (AI-assisted Intelligent Project System) is a system for managing project knowledge rather than project files.

Its goal is to preserve decisions, project state, evidence, and relationships between them so that both humans and AI always work with the same, current understanding of the project.

## Core Principles

- GitHub is the source of truth.
- Chat is a collaboration interface.
- Decisions are explicit.
- Project state reflects facts.
- Evidence confirms facts.
- Knowledge is traceable.
